Phần 1:
Hôm nay thầy sẽ dạy về C++. Trước hết chúng ta đi vào vector, vậy kiểu đó là gì, là một mảng động (cấu trúc lưu trữ dữ liệu) có khả năng tự động co giãn kích thước khi bạn thêm hoặc xóa phần tử, rất linh hoạt và không cần phải khai báo trước số lượng cố định như mảng thường.
Ví dụ thực tế: Hãy tưởng tượng vector giống như một chiếc balo đi học của em. Sáng đi học em chỉ bỏ 2 cuốn sách vào. Đến trưa em mượn thêm 3 cuốn nữa, chiếc balo này tự động nở rộng ra để chứa đủ 5 cuốn mà không bị rách hay chật chội. Cuối ngày em trả lại 1 cuốn, balo lại tự thu gọn lại cho vừa vặn.
Code làm quen:
C++
#include <iostream>
#include <vector> // Bắt buộc khai báo thư viện này để dùng vector


using namespace std;


int main() {
    // 1. Khai báo một vector chứa số nguyên (ban đầu rỗng, chưa có gì)
    vector<int> diemSo;


    // 2. Thêm phần tử vào cuối (giống như bỏ sách vào balo)
    diemSo.push_back(8); 
    diemSo.push_back(9);
    diemSo.push_back(10);


    // 3. Xem số lượng phần tử hiện có
    cout << "So luong diem hien tai: " << diemSo.size() << endl;


    // 4. Lấy phần tử đầu tiên ra xem (vị trí luôn tính từ 0)
    cout << "Diem dau tien: " << diemSo[0] << endl;


    // 5. Xóa phần tử cuối cùng (xóa số 10)
    diemSo.pop_back();
    cout << "So luong diem sau khi xoa: " << diemSo.size() << endl;


    return 0;
}
